# 🤔 澜澜的歪头动作

用户要求停止独立程序开发，改为把现有跳跃动作调整成歪头。这个版本沿用原生 Codex Pets，用五帧歪头动画替换第 4 行的 `jumping` 槽位。

动作依次为回正、开始歪头、明显歪头、眨眼、回正。双脚保持同一基线。客户端原来调用跳跃槽位的交互，现在会播放这条歪头动画。

精灵图仍为 v2 的 1536 × 2288 透明 PNG；行名和帧数保持兼容。其余十行逐像素保持不变，包括笔记本工作、复核、挥手、等待和十六向注视。素材替换沿用客户端的触发规则。

动画通过内置 ImageGen 生成，以当前已上传精灵图和原生待机帧为参考。第一版的最后一帧存在尾巴边缘问题，第二版修正了间距和完整性。随后使用 Pets 技能附带的分帧、检查、组装和边缘清理工具生成最终文件。

检查报告见 `qa/`。因用户明确把跳跃改为落地歪头，质量检查的最小起跳高度设为 0；其余透明度、完整性、基线和注视方向检查继续启用。这一语义覆盖同时记在 `qa/pet-quality.json` 中。

旧版跳跃素材保存在 `source/revisions/jumping-v2/`，旧验收报告保存在 `qa/history/community-animation-v2/`。独立程序草稿停留在仓库外，未发布。
