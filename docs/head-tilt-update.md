# 早期互动歪头（归档）

早期互动动作将第 4 行 `jumping` 槽位改为五帧歪头。当前 v3 使用[抵唇思考动作](seated-v3-update.md#动作设计)。

## 动作与配准

五帧依次为：回正 → 开始歪头 → 明显歪头 → 眨眼 → 回正。双脚保持同一基线，客户端调用第 4 行时播放该动作。

图集使用 sprite v2 的 `1536 × 2288` 透明 PNG。此次替换保留第 4 行的 5 帧结构，其余十行沿用原有像素。完整规格见[原生适配说明](dot-adaptation.md#配置与规格)。

动作通过内置 ImageGen 生成，以当时上传的图集和原生待机帧作为参考。生成后完成分帧、透明提取、配准、组装和边缘清理。该动作采用落地歪头，质量检查参数中的最小起跳高度设为 `0`。
