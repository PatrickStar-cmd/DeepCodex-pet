# dot 资料卡头像

Pets 保存动作图集，dot 资料卡保存独立的 `512 × 512` 静态头像快照。更新角色后，在形象编辑中保存快照，使资料卡采用新的坐姿形象。

## 保存与刷新

1. 按[云端更新流程](cloud-dot-update.md#更新已有角色)更新“大肥鱼”并激活。
2. 在 Pets 设置中查看角色，确认已加载 v3 坐姿素材。
3. 进入 dot 的形象编辑，选择桌宠“大肥鱼”并保存。
4. 返回资料卡，对照[坐姿头像参考](../assets/avatar-v3.png)检查显示。

刷新旧图时，先彻底退出并重开客户端，重新载入云端素材。保存按钮呈灰色时，先选择一个默认形象并保存，再改回桌宠“大肥鱼”并保存。

## 存储机制

头像记录使用 `avatar_type: codex-pet`，`avatar_manifest.pet_id` 指向宠物，`avatar_manifest.snapshot` 保存快照引用。客户端保存形象时，从宠物图集生成头像 PNG、上传快照，再更新 dot 资料。

资料卡使用静态快照；桌宠动画视图读取完整图集，播放待机、工作和互动动作。角色素材版本为 v3.2，原生图集格式为 sprite v2。

该存储流程记录于 2026-10-15，客户端版本为 `26.1007.9446.0`。图集参数见[原生适配说明](dot-adaptation.md#配置与规格)。
