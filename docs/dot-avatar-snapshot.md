# dot 仍显示旧站姿：头像快照与宠物图集

2026-10-15 在客户端 `26.1007.9446.0` 核查。角色素材版本 v3.2 与原生 sprite v2 文件格式是两件事；格式号 2 并不表示角色仍使用 v2 站姿。

## 为什么更新 Pets 后资料卡仍旧

Pets 保存完整动作图集。dot 的资料卡还保存独立的 512 × 512 头像快照，头像记录包含宠物 ID 和快照引用。客户端在保存 dot 形象时，从宠物生成头像 PNG，上传快照并更新 dot 资料；更换图集或再次激活同一宠物没有执行这个保存步骤。

此次回读确认云端图集已使用 v3 坐姿，用户截图却仍是 v2 站姿。客户端保存快照的独立路径解释了这个差异；Pets 的激活状态与图集像素校验不能证明资料卡已换图。

## 刷新资料卡头像

1. 先按[云端替换说明](cloud-dot-update.md)更新已有“大肥鱼”，保留原 ID 并激活。
2. 进入 dot 的形象编辑，重新选择桌宠“大肥鱼”并保存，让客户端从最新图集生成头像快照。
3. 如果同一形象无法再次保存，先选其他默认形象并保存，再改回桌宠“大肥鱼”并保存。
4. 返回资料卡，确认显示圆润的 v3 坐姿。资料卡快照是一张静态头像；它本身不播放眨眼。读取动作图集的桌宠视图才使用两态眨眼。

[`assets/avatar-v3.png`](../assets/avatar-v3.png) 是最新坐姿的静态参考。只替换本地文件或反复激活 Pets 不应当作头像快照已经刷新的证据。

## 验证范围

v3.2 图集已通过 Pets 预检，更新后下载文件的解码像素与上传原图一致，原角色仍激活。当前工具未提供 dot 快照保存能力；浏览器入口读取超时，因此本次未确认资料卡快照更新。最后一步须在客户端形象编辑中完成，不能将素材更新报告写成资料卡更新成功。
