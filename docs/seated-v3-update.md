# v3 坐姿与思考表情更新

日期：2026-10-15（Asia/Shanghai）。角色显示名：大肥鱼；原名：澜澜。

> 本文记录 v3 初版。本地待机使用 v3.1 的 72 帧连续晃头，云端兼容素材已在 v3.2 改为两态眨眼；见[待机流畅更新](idle-smooth-update.md)和[云端说明](cloud-dot-update.md)。其余动作槽位与初版相同。

## 画面与动作

- 全部状态统一为坐姿，双脚向前、裙摆落地，保留蓝色鲸尾、女仆头饰和蓝色蝴蝶结。
- 配色固定为靛蓝 / 钴蓝上部头发、青蓝发梢、藏蓝与白色服装、少量金色装饰；头部约占坐姿高度的一半。
- 待机六帧包含回正、左歪头、右歪头和眨眼。身体维持坐姿，坐姿下沿统一为 y=203。
- 工作六帧坐着使用笔记本，交替敲键、轻点头与眨眼；复核复用同一套笔记本素材。
- 原 `jumping` 槽位使用手指抵唇、圆嘴、大眼睛和小问号的思考表情。
- 十六向鼠标注视也使用同款思考表情。挥手、等待、挫折反馈均重做为坐姿。
- 移动槽位复用左右头部动作，位移仍由客户端负责；没有加入站立行走帧。

## 格式与客户端行为

**v3 是素材版本，`spriteVersionNumber` 仍是 2。** 本机加载器支持的 v2 图为 1536 × 2288，8 列 × 11 行，每格 192 × 208；不能为了产品版本把格式号改为 3。

本次只读复核的本机 Codex 包版本为 `26.1007.9446.0`。公开官方资料未提供这些精灵图槽位和悬停分支的完整契约，下列结论来自本机安装包，后续客户端更新可能改变行为。

- `avatar-mascot-button-11223c6d3a1d.js` 的 `E`：`onPointerEnter` 设置悬停，状态使用 `jumping`；离开恢复原状态。
- `app-initial-102e45562729.js` 的 `Mpo`：dot 的鼠标方向注视仅在动画开启、状态为 `idle`、精灵版本为 2 时启用；使用第 9、10 行素材。工作时仍显示笔记本，不会因方向注视切换表情。
- `Opo`：dot 使用 `loop: true`，持续工作时重复第 7 行。
- `Yco` / `rlo`：待机六帧时长为 `[1680, 660, 660, 840, 840, 1920]` ms，总计 6.6 秒；工作为 `[120, 120, 120, 120, 120, 220]` ms，总计 820 ms。
- `Hdo`：内容边界从待机首帧的 alpha 求得，其他状态共用定位规则。新首帧边界见 `qa/dot-compatibility.json`。

素材不负责改变 dot 的任务栏定位或调度策略。真实工作中的鼠标悬停行为、减少动态效果和窗口位置服从上述客户端规则。

## 制作、验证与回退

内置 ImageGen 以用户参考图生成新坐姿，通过固定坐姿锚点统一身份和配色；提示词保存于 `prompts/v3/`。右歪头曾出现蝴蝶结换边，单帧重绘后恢复到画面右侧。附加动作原图过于紧密，重新生成带透明留白的排版后再分帧。

`scripts/build-v3.mjs` 完成分帧、孤立 alpha 噪点清理、每套原图统一缩放、坐姿落点对齐、精灵图和预览打包。每个原图分组使用一个缩放比例，避免对每帧分别撑满网格。

运行 `node scripts/validate-dot.mjs` 检查原生字段、图像结构、SHA-256、全部 73 个有效槽位、15 个透明空白格和边缘留白；定位记录见 `qa/v3-registration.json`。

更新前精灵图和配置保存于 `source/revisions/pre-seated-v3/`。本机安装脚本还会在 `.codex/pets/deepcodex-lanlan/backups/` 备份已安装版本。

互动预览和素材验证不能替代真实 Codex 界面的全部交互复现。预览页的悬停和工作检查结果另见 `qa/v3-preview.json`；当前交付没有修改 Codex 客户端代码。
