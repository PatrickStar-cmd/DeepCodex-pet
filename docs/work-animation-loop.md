# 工作动画的播放方式（历史记录）

工作动作使用第 7 行 `running` 的六帧笔记本素材。桌宠按钮和 dot 分别采用以下播放方式：

| 记录日期 | 客户端版本 | 入口与播放方式 |
|---|---|---|
| 2026-10-09 | `26.1002.7124.0` | 旧版桌宠按钮使用默认有限播放，工作动作播放 3 轮后进入待机 |
| 2026-10-14 | `26.1007.9446.0` | dot 使用 `loop: true`，工作状态持续时循环播放第 7 行 |

## 时长与状态切换

| 参数 | 数值 |
|---|---|
| 工作帧时长 | `[120, 120, 120, 120, 120, 220]` ms |
| 单轮工作 | 820 ms |
| 旧版默认 3 轮工作 | 2460 ms |
| 原生待机槽位一轮 | 6600 ms |

工作轮数由客户端播放器参数控制。持续工作模式以 `running` 状态配合 `loop: true` 播放，任务状态改变时切换动作。Pets 更新用于角色名称、描述和图集，动作调度由客户端处理。

仓库的工作 GIF 使用无限循环，用于查看动作衔接；客户端从 PNG 图集读取帧，并按自身的播放参数调度。
