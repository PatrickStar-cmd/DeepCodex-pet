# 💤 闭眼点头，慢慢抬头

v5 将待机的六个原生帧位重新分配为：休息 → 半闭眼低头 → 闭眼浅点头 → 保持闭眼抬头 → 半睁眼继续恢复 → 休息。最低点提前到第三帧，第四、第五帧用于恢复；减少点头幅度，让抬头与睁眼依次发生。

新版相邻帧的头顶最大位置变化为 2 像素，上一版最低点到抬头为 5 像素。六帧保持同一身体比例，脚部水平中心范围为 0.94 像素；鞋底基线一致。测量和动作顺序见 [连续性记录](../qa/sleepy-continuity.json)，视觉效果见 [六帧图](../previews/sleepy-nod-stills.png)。

核查本机客户端后发现，待机帧会在基础时长上乘以六。因此本版 [待机 GIF](../previews/sleepy-nod.gif)、[待机 → 歪头 → 待机](../previews/idle-head-tilt-idle.gif) 和完整巡览均采用实际待机时长 `[1680, 660, 660, 840, 840, 1920]` 毫秒，一轮共 6.6 秒。[快速逐帧预览](../previews/idle-fast-review.gif) 用于检查姿态衔接，不代表客户端速度。

ImageGen 以当前上传的澜澜和原生待机姿态为参考生成六帧，再通过 Pets 技能的组件分帧、透明提取、整体平移配准、边缘清理、结构检查和质量门禁。除第 0 行外，其余十行逐像素保持原样，包括笔记本工作、复核、互动歪头和十六向注视。v4 源图、帧、提示词和预览保存在 `source/revisions/idle-v4/`，检查报告保存在 `qa/history/sleepy-idle-v4/`。
