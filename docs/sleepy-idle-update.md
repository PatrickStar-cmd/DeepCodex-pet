# 💤 待机时困倦点头

本次只修整平时待机的闭眼动作。六帧依次为休息、半闭眼、闭眼浅低头、闭眼轻点头、半睁眼抬头、回到休息姿态。中间姿态补在原生 `idle` 的六个槽位内，沿用客户端播放时长。

头部通过颈部轻轻前倾，头饰、耳鳍和刘海随之移动；双脚保持落地，手臂和裙子保持原有姿态。用鞋子位置进行平移配准，六帧鞋子水平中心的范围从约 2.85 像素缩小到 0.79 像素，脚底基线均为 202。检查了第六帧回到第一帧的循环衔接。

内置 ImageGen 以当前已上传精灵图和原生待机帧为参考生成。第一版的最后一条尾巴触及画布边缘；第二版使用六格布局参考和更小的源图比例，完整保留尾巴。随后使用 Pets 技能附带的分帧、检查、组装、透明边缘清理和质量门禁工具完成素材。

其余十行的所有 RGBA 像素均与上一版一致，包括已经改好的互动歪头、笔记本工作、复核、挥手、等待、失败和十六向注视。第 4 行继续沿用用户要求的落地歪头语义，因此质量检查保留此前起跳高度为 0 的覆盖；本次没有改变该动作。
